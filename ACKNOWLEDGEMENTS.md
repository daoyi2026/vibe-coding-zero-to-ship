# Acknowledgements and influences

This project is an original beginner-foundation skill informed by patterns seen across several open-source and public workflow projects.

Useful influences include:

- VibeCheck — product discovery, project memory, and beginner-aware guardrails  
  https://github.com/8bitAlex/VibeCheck
- vibe-coding-onboarding — non-technical onboarding and agent-performs-the-command interaction model  
  https://github.com/moth-flame/vibe-coding-onboarding
- vibe-security-skill — proactive secret, auth, database, payment, and production security thinking  
  https://github.com/raroque/vibe-security-skill
- VibeSubin — layperson-oriented technical translation  
  https://github.com/subinium/vibesubin
- AWS sample AI Product Discovery & Strategy — lightweight product discovery concepts  
  https://github.com/aws-samples/sample-ai-pds-desktop

The repository does not intend to reproduce those projects wholesale. Its focus is the missing beginner foundation layer: concepts advanced coding workflows often assume are already understood.

The structure follows the public Agent Skills convention: a focused `SKILL.md` manifest/router with supporting files loaded progressively as needed.
